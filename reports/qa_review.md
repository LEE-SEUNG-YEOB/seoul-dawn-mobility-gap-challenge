# 독립 QA 결과

검토 대상은 통합 체크포인트 `d94d668`이며 준비 상태는 `separate_only`다. QA 역할은 결과 파일을 수정하지 않고 재현성, 수치, 시간·공간 단위, 결측·중복, 지도·그림과 주장 범위를 독립 검토했다.

## 통과 항목

- 전체 24개 테스트 및 역할별 테스트 통과
- 18개 데이터셋 계약과 전체 입력 SHA256 검증 통과
- `demand_candidates.csv` 100행, 동내 OD 0행, 후보 이름 결측 0행
- 월~금 22일, 토~일 8일과 출발시각 `[03:00,06:00)` 필터 확인
- 목적축과 수단축을 합산·차감하지 않은 점 확인
- OA-15334 요청완료 1,999쌍, 유효 1,947쌍, 미완료·미요청 42,736쌍 구분 확인
- `transit_coverage_audit.csv` 1,947행 모두 `access_gap_status=unknown`, `reachable`과 도착 마감 공란 확인
- `service_gap_candidates.csv`가 생성되지 않은 점 확인
- SGIS 경계 426개 중 생활이동 코드 연결 425개, 분할 관련 `unknown` 3개 감사행 확인
- 중간 표와 최종 표의 바이트 일치, GeoJSON 행수, 지도·그래프 8개의 제목·축·범례·주석과 잘림 없음 확인
- 보고서 반복 생성 후 Git 차이가 없어 결정적 재생성을 확인
- `git diff --check` 통과, 원자료·인증정보 비추적 확인

치명적·중요 수치 또는 논리 문제는 발견되지 않았다.

## 경미 사항과 처리

- 일부 데이터셋은 로컬 근거가 없는 출처 URL·접근일·정확한 라이선스 버전을 `null` 또는 미검증으로 유지한다. `analysis_coverage.md`와 계약에 영향과 다음 검증 단계를 공개했다.
- README의 공급자료 “확보 완료” 표현은 역사적 유효성과 실제 운행까지 검증한 것으로 읽힐 수 있어 로컬 스냅샷 확보 및 미검증으로 수정했다.
- `artifact_manifest.json`은 최종 수정 뒤 생성하고 즉시 검증한다.
- 최종 전체 재현에서 병렬 `DOUBLE` 합산이 일부 파일의 마지막 소수 자리를 바꾸는 문제를 추가로 발견했다. 원자료 `cnt` 정의에 맞춰 `DECIMAL(38,2)`로 합산하도록 수정했고, 수요 산출물 20개를 연속 두 번 재생성하여 SHA256이 모두 동일함을 확인했다.

## 결론

준비 상태와 실제 산출 범위가 일치한다. 미확보 자료는 `unknown`, 계산할 수 없는 결과는 `unsupported`로 유지했다. 최종 상태는 `COMPLETE_LIMITED`가 적절하다.
