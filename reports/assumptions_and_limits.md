# 분석 정의와 한계

## 공통 범위

- 대상 기간은 2026-09-01부터 2026-09-30까지이며 시간대는 Asia/Seoul이다.
- 새벽 출발 시간은 `[03:00, 06:00)`이다. 도착 시간 기준 결과는 별도로 표시하며 혼합하지 않는다.
- 생활이동 `cnt`는 통신 기반 추정 이동량이다. 월간 이동량 합계를 서로 다른 개인 수나 근로자 수로 해석하지 않는다.
- 로컬 생활이동 매뉴얼 PDF p7·p12는 가입자 집계를 인구 기준으로 보정하는 방법을 설명한다. p19~22는 소수점 추정값 및 출퇴근대 20분 단위를 설명한다. 소량 셀의 공개 억제 임계값은 확인되지 않아 `unknown`이다.
- 이동 목적은 추정 분류이며 직종, 근무 시작 시각, 체감 불편, 대체수단 이용 이유, 지불 의향을 확인하지 못한다.
- 평일·주말은 달력상 월~금 / 토~일 구분이다. 별도의 검증된 공휴일 캘린더 없이는 영업일·비영업일로 부르지 않는다. 일수 차이를 제거한 일평균으로 비교한다.
- 공개 시간 코드의 실제 세분화가 있더라도 이것만으로 첫차 15분·30분 조정 효과를 검증할 수 없다.
- 모델이 단순 집계보다 추가로 검증 가능한 가치를 제공할 근거가 없어 군집화·예측 모델은 사용하지 않는다.

## 수요와 공급의 분리

- 이동량 순위는 **수요 측 후보**다. 미충족 수요, 버스 부재의 결과 또는 서비스 조정 우선순위로 부르지 않는다.
- 통신 이동량과 교통카드 승하차량은 집계 모집단·측정 방식·단위가 다르다. 두 값을 빼서 미충족 수요를 추정하지 않는다.
- OA-15334는 비확률 수집분이다. 미확보 정류소–노선 쌍의 시간과 접근성은 `unknown`이며 0이나 `no_gap`으로 대체하지 않는다.
- 수집 범위의 첫차 예정시각은 계획 정보다. 실제 도착, 만차·결행, 환승 성공, 보행 접근 가능성이나 특정 도착 마감시각을 보장하지 않는다.
- 교통망 마스터·시간표의 수집일과 대상 이동 월이 다르면 9월의 역사적 공급을 확정할 수 없다.
- `join_ready=false`이면 서울 전체 공급 공백 순위, 첫차 조정 노선 순위, 수혜 인원, 운행시간당 수혜, 탄소 효과와 정밀 조정 시나리오는 `unsupported`다.

## 공간 자료

- SGIS 2025년 2분기 경계와 생활이동 2026년 8월 코드북은 코드 체계가 다르다. 코드값이 비슷해도 직접 연결하지 않는다.
- 지도는 구명과 동명의 유일한 일치를 확인한 뒤 연결한다. 가운데점 `·`과 마침표 `.`만 정규화한다.
- 용신동 경계와 이후 신설동·용두동 코드처럼 분할이 있는 경우 면적이나 인구 비례로 임의 배분하지 않는다. 미매칭은 `unknown`이다.
- 이 지도는 과거 경계에 현재 분석값을 표시하는 참고도다. 2026년 9월 행정경계 일치 여부를 검증한 지도가 아니다.
- CRS는 원 `.prj`에서 읽고 경도·위도 순서의 WGS84로 변환한다. 경계의 대표점이나 중심점은 실제 출발지·정류소를 의미하지 않는다.

## 추가 검증

서울 전역 효과 검증에는 완전한 정류소–노선 예정시각, 분석 월 서비스 캘린더, 정류장 간 이동·환승·보행 연결, 검증된 시간·공간 수요 연결이 필요하다. 체감 불편과 수단 전환 의향은 설문·현장 검증 대상이다. 현재 작업에서는 추가 수집하지 않는다.
