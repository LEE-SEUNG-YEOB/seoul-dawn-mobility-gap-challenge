1. 「첫차가 오기 전에 출근하는 사람들」 — 새벽 이동 공백 분석과 첫차 조정
최근 이슈와 연결
서울시는 2026년 4월 안내에서 기존 A160·A741에 이어 A148 새벽동행 자율주행버스 확대를 소개했습니다. A148은 상계역∼고속터미널 구간에서 평일 새벽 3시 30분부터 운행하는 서비스입니다. 새벽 출근자의 이동이 실제 정책 과제로 다뤄지고 있다는 근거가 됩니다. 서울시 안내, 2026.4.14
여기서 연구 질문을 **“새벽버스를 추가로 도입한다면 어느 구간부터 지원해야 하는가?”**로 발전시키는 겁니다.
활용할 데이터
구분   데이터   분석에서 하는 역할
공공   버스 노선·정류장 위치·첫차 및 배차 정보   새벽에 이용 가능한 교통서비스 파악
공개된 민간 기반 데이터   서울시·KT 생활이동 데이터   시간대별 출발지·도착지 간 이동 규모 파악
공개된 민간 기반 데이터   교통카드 기반 정류장별·시간대별 승하차   실제 첫차 시간대 이용 집중 구간 확인
직접 수집   새벽 근로자 대상 짧은 설문·인터뷰   출근시각, 택시비, 환승 불편 등 검증


서울 생활이동은 KT 통신자료를 활용한 추정 데이터이며, 공개 자료와 별도 이용 절차가 있는 세밀한 자료가 구분됩니다. 버스 승하차 정보도 서울시가 티머니로부터 제공받아 공개하는 자료입니다. 민간 원자료를 직접 구매하지 않고도 민간 기반 자료를 활용할 수 있다는 점이 장점입니다. 서울 생활이동 · 버스 데이터 제공 안내
분석 방법
1. 서울의 특정 생활권을 정하고 새벽 3∼6시 이동이 집중되는 출발지·도착지를 찾습니다.
2. 해당 이동이 현재 첫차와 환승으로 가능한지 비교합니다.
3. 이동은 관측되지만 대중교통으로 제시간에 도착하기 어려운 구간을 선별합니다.
4. ‘첫차 15분 앞당김’, ‘30분 앞당김’, ‘새벽 단축노선 1개 추가’를 비교합니다.
AI는 비슷한 새벽 이동 패턴을 묶고 수요를 예측하는 데 사용합니다. 최종 노선·시간 조정은 차량 운행시간과 예산 제약을 넣어 비교하면 됩니다.
제안할 정책과 결과물
- 첫차 조정 우선 노선과 정류장 목록
- 시간 조정 전후 도착 가능 지역 지도
- 추가 운행시간당 혜택을 받는 예상 이용자 수
- 승용차·택시에서 버스로 전환하는 비율에 따른 탄소배출 변화 시나리오
차별화 포인트: 기존 승객 수만 보면 버스가 없어 이용하지 못하는 사람을 놓칠 수 있습니다. 통신 기반 이동을 함께 사용해 현재 승하차 통계에 충분히 나타나지 않는 수요를 찾는 것이 핵심입니다.
다만 통신자료의 이동 목적은 추정치이고, 특히 교대근로자는 일반적인 출퇴근 분류와 다를 수 있습니다. ‘새벽 이동자=새벽 근로자’로 단정하지 말고 인터뷰로 보완하는 편이 좋습니다.
