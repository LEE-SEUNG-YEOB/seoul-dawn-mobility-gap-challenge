# 새벽 이동 공백 분석 프로젝트 맥락

## 분석 질문

서울의 새벽 03:00~06:00 이동 중 수요는 존재하지만 현재 첫차와 환승으로 제시간 도착이 어려운 구간을 찾고, 첫차 조정 또는 새벽 단축노선 도입의 우선순위를 정량화한다.

공모전은 AI와 다양한 데이터를 활용해 기존 정책에서 잘 드러나지 않은 교통문제를 발견하고, 이동 격차 감소와 탄소중립에 기여할 아이디어를 요구한다. 2026년 공고상 접수 기간은 8월 18일부터 10월 22일까지다. 실제 작업 시 공식 공고의 최신 상태를 다시 확인한다.

공모전 원문:

- 공식 공고: https://koreashe.org/notice/?mod=document&uid=95427
- 보조 안내: https://linkareer.com/activity/347433

## 데이터 분석 전용 범위

이 저장소는 분석 코드와 근거 산출물만 만든다. 공모전 분석보고서 양식에 넣을 기획 서사, 참가신청서, 정책 제안서와 발표 원고는 다른 팀원이 작성한다.

팀원에게 전달할 것은 다음과 같다.

- 데이터 출처와 접근 조건
- 재현 가능한 수집·정제·분석 코드
- 결과표, 지도, 그림과 기계 판독 파일
- 시나리오 계산식과 가정
- 불확실성, 한계와 해석상 주의점
- 재현 명령

## 단계 구분

1. 공개 행정동·1시간 단위 자료로 03시·04시·05시대 주요 OD와 후보 생활권을 찾는다.
2. 정류장별 첫차 도착시각, 노선 순서, 지하철 시간표를 결합해 현행 도착 가능성을 계산한다.
3. 생활이동 규모와 교통카드 승하차 간극으로 미관측 수요 후보를 찾는다.
4. 현행, 15분 조정, 30분 조정, 단축노선 시나리오를 같은 가정에서 비교한다.
5. 최종 후보만 캠퍼스 세밀 자료와 설문으로 검증한다.

## 핵심 해석 제한

- 새벽 이동자는 새벽 근로자와 동일하지 않다.
- 생활이동의 목적은 추정치이며 교대근로가 일반 출퇴근 분류와 다를 수 있다.
- 생활이동은 많고 버스 승차가 적은 현상은 버스 부재뿐 아니라 귀가·쇼핑·기타 이동 때문일 수 있다.
- 공개 1시간 자료만으로 15분과 30분 조정의 차이를 정밀하게 검증하기 어렵다.
- 정밀 검증 자료는 이용 신청, 현장 분석과 반출 심사가 필요할 수 있다.
- 노선 기점의 첫차 출발시각이 아니라 정류장별 첫차 도착시각을 사용해야 한다.

## 목표 결과물

- 첫차 조정 우선 노선·정류장 후보표
- 조정 전후 도착 가능 지역 지도
- 추가 운행시간당 예상 수혜 인원
- 승용차·택시에서 버스로의 전환율별 탄소배출 변화 민감도
- 후보 선정 규칙, 데이터 한계와 재현 방법
